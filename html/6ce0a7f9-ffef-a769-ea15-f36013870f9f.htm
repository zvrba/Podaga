      Mix

      Implements "twisted tabulation" to improve collision resistance of linear probing. See M. Thorup: "Fast and Powerful Hashing Using Tabulation".

      The mixing table is of size 4x256 characters and is filled as start-up using RandomNumberGenerator as the source of random numbers. This means that the method will return different value for the same input between program runs.
