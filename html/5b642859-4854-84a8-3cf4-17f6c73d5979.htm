      Remarks

      These extension methods can automatically adapt IComparerT to ITaggedValueComparerT. The adaptated comparer defines all additional operations (including value cloning) as no-ops.

      Methods

      NewCollectionT Creates a new ICollectionT backed by an AVL tree using comparer.
      NewDictionaryT, TKey, TValue Creates a new IDictionaryTKey, TValue backed by an AVL tree using comparer.
      NewSetT Creates a new empty ISetT backed by an AVL tree using comparer.
