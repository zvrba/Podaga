      Remarks

      Implementations of set operations check whether the IEnumerableT argument is actually an instance of JoinableTreeNodeT or IAdaptedJoinableTreeT. If so, a more efficient join-based recursive strategy is used. Otherwise, the operation is performed element-wise. In particular, IntersectWith(IEnumerableT) allocates temporary storage in size proportional with the result.
