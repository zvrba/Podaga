      TSelf
      The most-derived type implementing this interface. This may be a struct. There is no CRTP constraint to allow arbitrary casts at run-time.

      Properties

      InternCode Cached value of the object's hash code. When this is non-null,
      • This value MUST be returned by GetHashCode.
      • The object has been interned and it MUST disallow changes to any property that affects hash code or equality.
