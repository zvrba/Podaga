      FindT Finds a value equivalent to value beginning from the node at the top of the stack. The stack is extended with the path to the last visited node.
      FirstT Extends this with the path to the leftmost node starting from the node at the top of the stack.
      LastT Extends this with the path to the rightmost node starting from the node at the top of the stack.
      NthT Sets this to the n'th element in sorted order (wrt. the node at the top of the stack).
      PredT Moves this to the previous element in sort order (wrt the node at the top of the stack).
      SuccT Moves this to the next element in sort order (wrt the node at the top of the stack).
