      Podaga.Interning Namespace

      This namespace contains types related to interning, weak hash and memoization.

      Classes

      AbstractInternableTSelf Convenience class for simplifying the implementation of IInternableTSelf.
      InternableExtensions Extension methods over IInternable.

      InternableListT Internable IListT. When T implements IInternable, the list interns every element before interning itself.
      ObjectInternedException Thrown when attempting to mutate an interned object. Unless inherited, this exception is thrown only by ThrowIfInterned(IInternable).
      TwistedTabulation Helper methods for implementing an open addressing hash table.
      WeakHash Implements IInternator using hashing with open addressing. This class is not suitable for interning struct types because they will be boxed.

      Structures

      MemoizeTInput, TOutput Generic wrapper for memoized execution of methods. Each instance carries own memoization history. The constructor MUST be explicitly invoked; a default instance is invalid to use.

      Interfaces

      IInternable This interface marks "internable" objects: those that have only a single copy in the system. All internable objects MUST override Equals(Object) and GetHashCode. This interface is used only by IInternator implementations; internable classes must implement IInternableTSelf.
      IInternableTSelf An internable type must implement this interface.
      IInternator An instance of this object manages IInternable instances, ensuring that only one equal copy is present in the interning hash table.

      Delegates

      MemoizedTInput, TOutput Memoized functions must conform to this delegate.
