      Type Parameters

      T
      Type of elements stored in the list. This type is restricted, at run-time, to either structs or instances of IInternable.

      Remarks

      The static constructor throws ArgumentException when T is neither an IInternableTSelf or a value type.

      This class implements small-storage optimization: when the number of elements is less than MaxSmallCount, they are stored inline in the instance itself. Otherwise, ListT is used as the underlying storage.
